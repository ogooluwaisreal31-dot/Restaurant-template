# TastyBites reusable restaurant website template

A responsive, single-page restaurant website template built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `config.js` — edit restaurant details, menu, prices, colours, contact information, and image URLs
- `script.js` — renders menu/gallery and creates WhatsApp order links

## Preview locally
Open `index.html` in a browser. Some browser/editor environments may restrict local file loading; if that happens, run it in a browser-based static web editor or publish it to a static host.

## Customize for a client
1. Open `config.js`.
2. Replace the demo restaurant name, tagline, contact details, address, hours, menu, prices, and photos.
3. Set `whatsapp` to the restaurant's WhatsApp number in international format without `+`, spaces, or leading zero. Example format: `2348012345678`.
4. Set `phoneDisplay` and `phoneDial`.
5. Check every link, image, price, and spelling with the client.
6. Test on a phone and desktop before publishing.

## Important
- All business information and prices are fictional sample data. Confirm all details with the restaurant before publishing.
- Images are loaded from external Unsplash URLs, so an internet connection is required. Replace them with client-approved images and confirm image usage rights.
- The WhatsApp button opens a pre-filled message; it does not process payments or confirm orders automatically.
- This is a static website. It does not include an admin dashboard, online payment processing, order database, or automatic order management.
- Hosting and custom-domain terms and limits can change. Confirm the provider's current terms before using it for paid client work.
